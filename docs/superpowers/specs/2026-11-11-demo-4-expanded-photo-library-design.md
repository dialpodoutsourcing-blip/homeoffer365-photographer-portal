# Demo 4 Expanded Photo Library Design

Demo 4 will present a complete, real-estate-agent-style property record with exactly 12 exterior, 24 interior, 8 basement, and 10 mechanical photographs. A new Basement tab sits between Interior and Mechanicals. The existing basement overview moves from Mechanicals into Basement.

Every gallery entry uses a unique file and a materially different viewpoint. Generated photos depict the same modest red-brick American bungalow, remain clean and realistic, contain no people, text, logos, or watermarks, and avoid implausible luxury remodeling. Interior coverage follows a natural tour; basement coverage documents structure and access; mechanical coverage documents distinct systems.

The implementation verifies exact category counts, globally unique asset paths, file existence, and nontrivial file sizes. Visual contact sheets are reviewed for repeated compositions and property inconsistency before release.
